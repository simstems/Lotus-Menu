# Lotus-Menu

![Lotus_boot](https://github.com/user-attachments/assets/029b4b30-81d7-48c0-8a14-ca9b2a5d36e0)

This a program that takes its inspiration from Hirens BootCD. It is a fully customizable software multitool written in Python. I wrote it for SysAdmins to easy navigate systems remotely without memorizing a bunch of code or steps. Store your most used scripts in the script menu and easy have them at your disposal at alll times. I hope you enjoy. Many more to come.
